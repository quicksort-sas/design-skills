# Quicksort design skills

Agent Skills for designing in the Quicksort style: the brand rules, colour and type tokens, logo, pixel icons and isometric figures.

## Install

```sh
npx skills add quicksort-sas/design-skills
```

This works with Claude Code, Cursor, Codex and other agents that support Agent Skills. To install by hand, copy `skills/quicksort-design/` into your agent's skills folder (for Claude Code: `~/.claude/skills/`).

Then ask, for example: "Make a LinkedIn cover for our next event in the Quicksort style."

## Skills

| Skill | What it does |
|---|---|
| [`quicksort-design`](skills/quicksort-design/SKILL.md) | The Quicksort brand and design system, with the asset files to use |

The full guidelines are at [quicksort.design/toolkit](https://quicksort.design/toolkit.html). This repository is published from the `skills/` folder of the quicksort.design site; change the skill there, then copy it here.
